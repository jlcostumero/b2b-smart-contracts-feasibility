# Habilidad: Abogado del Diablo (Red-Teaming y Contra-Análisis)

Esta habilidad contrarresta el sesgo de confirmación y el optimismo ingenuo característico de los modelos de lenguaje, sometiendo cada idea de negocio a un ataque conceptual riguroso.

## Protocolo de Demolición de Hipótesis
1. **La Prueba de la Alternativa Web2:**
   - ¿Por qué usar una blockchain si esto se puede resolver de forma más rápida, barata y sencilla con una base de datos PostgreSQL y una API REST tradicional? Si no hay una respuesta contundente basada en censura, auditoría inmutable o liquidación atómica, el modelo se tambalea.
2. **Análisis de Competencia Incumbente:**
   - ¿Quién ofrece ya un servicio similar en el mercado? Si existe un competidor establecido con millones en volumen y efecto de red, ¿por qué un usuario confiaría en un contrato nuevo no auditado?
3. **Puntos Ciegos y Fricciones de Adopción:**
   - ¿Requiere que el usuario firme transacciones complejas o tenga gas en una red específica?
   - ¿Qué pasa si el volumen cae a cero? ¿Quién asume los costes fijos de servidores y oráculos?
4. **Veredicto Final:**
   - **SOBREVIVE:** El modelo resiste los contra-argumentos con hechos contrastables y una propuesta de valor indiscutible.
   - **TUMBADA:** Se detectan supuestos erróneos, inviabilidad económica real o falta de ventaja competitiva insalvable.
